# LeadInspect — Frontend Client

This is the React + TypeScript frontend for the Lead Quality Inspector dashboard.

## Tech Stack
- **React 18**
- **TypeScript**
- **Vite**
- **Lucide React** (icons)
- **Vanilla CSS**

## Running Locally

From this directory:

```bash
npm install
npm run dev
```

For full documentation, architecture specifications, and backend setup instructions, please refer to the [Root README](../README.md).
